# Code signing policy

Oshabe is open source (MIT). We are applying for free Windows code signing from the SignPath Foundation. This page is the policy that application requires.

- **What is signed:** Windows installers built from this repository's public GitHub Actions workflow. Nothing is signed from a developer machine.
- **Who can approve a release:** the maintainer, Dev Trivedi (Hikari Webworks). All other contributors go through pull requests and review.
- **Privacy:** Oshabe does not collect or send personal data. Speech recognition runs on your device. See the Privacy section of the README.
- **Not signed:** macOS builds are currently unsigned and not notarized. Open them with right click, Open the first time.
- **Reporting a problem:** see SECURITY.md.

Until signing is approved, Windows SmartScreen may show a warning. Choose More info, then Run anyway.
